# Synthetic samples

`raw-krl/DEMO.SRC` and `raw-krl/DEMO.DAT` are newly authored synthetic fixtures for the future files-only quickstart. They contain no motion commands or vendor assets. They have not been submitted to KUKA.Sim or native KSS and are not qualified for use on a controller.

The intake and receipt-verification commands will be documented after import audit. A synthetic ValidationPackage will be authored against the imported schema in that stage; none is provided yet. Do not invent a package format or reuse private production artifacts to fill that gap.
